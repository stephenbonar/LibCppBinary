Lib\+Cpp\+Binary is a modern, cross-\/platform C++ library for reading and writing binary data to /\+ from files using the provided field, data structure, and stream classes.\hypertarget{md__r_e_a_d_m_e_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{md__r_e_a_d_m_e_autotoc_md1}

\begin{DoxyItemize}
\item Binary data field classes allow for easy manipulation of binary data
\begin{DoxyItemize}
\item {\ttfamily Binary::\+\+Raw\+Field} allows manipulation of fields without interpretation
\item {\ttfamily Binary::\+\+String\+Field} allows manipulation of string fields
\item {\ttfamily Binary::\+\+Int\+Field} template allows manipulation of integer fields
\begin{DoxyItemize}
\item The following template specializations are available:\+
\begin{DoxyItemize}
\item {\ttfamily UInt8\+Field}
\item {\ttfamily Int8\+Field}
\item {\ttfamily UInt16\+Field}
\item {\ttfamily Int16\+Field}
\item {\ttfamily UInt24\+Field}
\item {\ttfamily Int24\+Field}
\item {\ttfamily UInt32\+Field}
\item {\ttfamily Int32\+Field}
\item {\ttfamily UInt64\+Field}
\item {\ttfamily Int64\+Field}
\end{DoxyItemize}
\end{DoxyItemize}
\item {\ttfamily Binary::\+\+Data\+Field} base class allows for future extensibility
\item Int\+Fields can manipulate both little and big endian formats and convert between the two. By default, Int\+Fields follow the endianness of the platform but can be changed to the opposite endianness as fields in binary files can often differ from the platform the program is running on.
\item Int\+Fields provide methods that handle the conversion of the raw bytes to native integer types using the correct endianness so you don\textquotesingle{}t have to do the conversions yourself.
\item All data field classes provide To\+String() methods that return a text representation of the binary data in an appropriate default format but a specific format can be specified. Possible formats include:\+
\begin{DoxyItemize}
\item {\ttfamily Terminated} :\+ Formats as null-\/terminated string
\item {\ttfamily Raw} :\+ Formats the string data "{}as-\/is"{} using the bytes.
\item {\ttfamily Printable} :\+ Replaces any non-\/printable chars with a space.
\item {\ttfamily Bin} :\+ Binary representation in 1s and 0s.
\item {\ttfamily Hex} :\+ Hexadecimal representation.
\item {\ttfamily Dec} :\+ Decimal representation. Only use for int fields.
\end{DoxyItemize}
\item Binary data structure classes allow you to group binary fields for reading and writing data fields in order as one chunk from /\+ to a file.
\begin{DoxyItemize}
\item The {\ttfamily Binary::\+\+Data\+Structure} base struct allows you to build your own groupings of {\ttfamily Binary::\+\+Data\+Field} objects.
\item The {\ttfamily Binary::\+\+Chunk\+Header} data structure allows you to read and write tagged chunks such as IFF /\+ RIFF tags from media files.
\end{DoxyItemize}
\item Binary stream classes allow reading and writing from /\+ to files and memory
\begin{DoxyItemize}
\item {\ttfamily Binary::\+\+File\+Stream} allows for reading and writing from /\+ to files. It is a base class derived from {\ttfamily Binary::\+\+Stream} both for extensibility purposes and so mock file streams can be used with tests.
\item {\ttfamily Binary::\+\+Standard\+File\+Stream} is the standard implementation of File\+Stream.
\item {\ttfamily Binary::\+\+Buffer\+Stream} allows for reading /\+ writing data in memory.
\item {\ttfamily Binary::\+\+Stream} base class allows for future extensibility.
\item All binary stream classes support reading and writing all types that derive from {\ttfamily Binary::\+\+Data\+Field} and {\ttfamily Binary::\+\+Data\+Structure}
\item All streams support finding chunks and sub-\/chunks using chunk IDs.
\end{DoxyItemize}
\end{DoxyItemize}
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{md__r_e_a_d_m_e_autotoc_md2}

This library is designed to be included directly into your project rather than being built /\+ installed as a dynamic library, although you could do either. The easiest way is to add the following to your CMake\+Lists.\+txt file in your own CMake project:\+

include(\+Fetch\+Content) Fetch\+Content\+\_\+\+Declare( Lib\+Cpp\+Binary URL \href{https://github.com/stephenbonar/LibCppBinary/archive/HASH.zip}{\texttt{https:\+/\+/\+github.\+com/\+stephenbonar/\+\+Lib\+Cpp\+Binary/\+archive/\+\+HASH.\+zip}} )

Where HASH is the SHA hash for the specific commit of the library you want to include, which most likely should be the commit of the most recent stable release version of the library. Replace HASH with the specific commit hash you want to use.

You then need to link the library to your project\textquotesingle{}s CMake target by adding this line to your CMake\+Lists.\+txt:\+

target\+\_\+link\+\_\+libraries(\+YOUR\+\_\+\+TARGET Lib\+Cpp\+Binary)

Where YOUR\+\_\+\+TARGET is the name of your project\textquotesingle{}s CMake build target.

Finally, to include the library header into your source files:\+
